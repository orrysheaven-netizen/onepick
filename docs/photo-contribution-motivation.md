# 사진 기여: 선택형 안내와 등록자 표시

## 사용자 이용 / UX
- 기존 원픽 선택 완료 화면(`/pick/choose`)에서 저장이 확인된 뒤에만 `내가 고른 [상품]에 사진도 남겨볼까요?`를 제안한다.
- `내 원픽 보기` 및 `다른 사람의 원픽 계속 보기`를 기본 동선으로 유지한다. 사진 요청은 하단의 별도 선택 영역이며 `지금은 넘어가기`로 닫는다. 사진을 올리지 않아도 저장 결과는 유지된다.
- 최신 정상 상품 조회에서 이미지가 없고 active/discontinued인 경우만 안내한다. 업로드 이미지·외부 포스터가 있거나 조회 상태를 확인할 수 없으면 숨긴다. 오래된 저장 스냅샷만 보고 빈 사진으로 판단하지 않는다.
- `사진 등록`은 기존 상품 상세의 `photo=1` 모드로 이동한다. 중복 탭을 막고, 이 이동은 원픽 저장이나 사진 업로드를 수행하지 않는다. 댓글 위치보다 사진 입력을 우선한다.
- 상품 상세에는 실제 채택 사진에 대해 작은 `사진 등록 · @사용자명`을 표시하고 해당 프로필로 연결한다. 홈 카드의 주인공은 원픽 등록자이며 기여자를 별도 노출 순위로 사용하지 않는다.
- 사진 선택 전 상품 이름이 잘 보이면 충분하다는 안내, 공유 권한 확인, 공용 이미지 사용 및 공개 사용자명 표시에 대한 안내를 보여준다.
- 기존 사진 선택 → 미리보기/공유 확인 → 등록 절차를 재사용한다. 새 폼, 필수 사진, 포인트, 배지, 순위, 팔로우 알림, 추가 팝업은 없다.
- 기존 종합 등록 화면의 선택형 사진 입력은 유지한다. 상품 식별 정보를 다시 입력하는 별도 사진 등록 절차를 만들지 않는다.

## 백엔드 / 보안
- 새 item_photo_credits는 현재 채택된 저장소 원본/썸네일 쌍의 동일한 소유자만 기록한다. 상품 created_by나 업로드 시도자의 자기신고 ID로 추정하지 않는다.
- DB 트리거는 이미지가 실제로 변경된 트랜잭션에서만 기여자를 계산한다. 기존 첫 이미지 우선/동시 요청 규칙 및 업로드 검증은 그대로 유지된다.
- 기존 사진을 일괄 역추적하지 않는다. 등록자가 확인되지 않는 사진이나 외부 포스터에는 사용자 크레딧을 만들지 않는다.
- 사진 삭제/교체 시 이전 기여자 표시는 제거 또는 새 이미지 소유자로 갱신한다. 사용자명은 현재 프로필을 조회해 반영한다.
- 클라이언트는 기여 기록을 직접 생성/수정/삭제할 수 없다. RLS와 SECURITY INVOKER 조회가 상품/프로필 공개 범위, 일반 사용자 간 차단, 정지, 계정 삭제를 따른다.
- 기여 표시는 저작권자/촬영자 인증이 아니다. 가져온 이미지를 올렸더라도 `사진 등록`으로만 표기한다.
- 기여 조회는 상품 조회와 분리되어 실패해도 상품/댓글 화면을 막지 않는다. 사용자·사진별 캐시와 이미지 경로 일치 검사로 다른 사진의 크레딧을 잘못 붙이지 않는다.

## 소수 테스트에서 확인할 것
- 사진 없는 상품을 저장해 안내가 실제 표시된 경우만 대상 기회로 집계한다.
- 안내 확인 → 사진 등록 선택 → 업로드 성공/채택 여부, 넘어가기, 사용할 사진 없음과 업로드 실패를 구분한다.
- 사진이 채워진 상품 비율을 확인하고 업로드 수만 늘리려 하지 않는다. 실제 통계 수집기나 자동 분석 시스템은 이번 변경에 추가하지 않았다.

## 배포 보류
같은 PR #11에서 준비한다. 새 마이그레이션은 운영 DB에 적용하지 않고, main/Cloudflare/Vercel 운영 배포도 변경하지 않는다. 검증은 코드/CI이며 실제 기기의 파일 선택·사진 표시 및 소수 사용자 동기 검증은 별도 단계다. 공용 사진 신고/관리자 정정 UI는 여전히 별도 운영 준비 항목이다.

## 2026-10-01 변경 — 새 원픽은 사진 필수 (#622)
- 사용자 결정: 사진이 없는 원픽은 생기지 않아야 한다.
- `/pick/choose`에서 사진 없는 기존 상품을 새 원픽으로 고르거나 원픽을 이 상품으로 바꿀 때, 화면 안의 `1. 대표 사진` 단계가 **필수**다. 사진이 저장되기 전에는 원픽을 저장하지 않고 "사진을 먼저 등록해주세요"를 표시한다. 입력한 한줄평은 유지된다.
- 아래 저장 후 사진 제안은 이제 **기존 원픽의 한줄평만 수정**했고 상품에 아직 사진이 없을 때만 나타난다. "지금 사진이 없어도 괜찮아요" 문구는 제거했다.
- `/pick/new`(원픽 등록 v6)는 이미 사진 없는 상품에 `PHOTO_REQUIRED`를 적용하고 있어 변경하지 않았다.
- 서버(`choose_pick`)는 아직 사진 여부를 검사하지 않는다. 앱 밖 경로까지 막으려면 별도 DB 변경이 필요하다.
