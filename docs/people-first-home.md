# 사람의 취향을 먼저 보는 홈

## 사용자 이용 / UX
- 목표 흐름: 다른 사람의 **지금의 원픽**과 한줄평을 읽는다 → 취향이 같은지 다른지 발견한다 → 궁금한 메뉴·제공처를 더 살펴본다 → 필요할 때 내 원픽을 고른다.
- 홈은 "게시물" 피드가 아니라 현재 원픽 피드다. 카드마다 별도의 게시물 본문을 두지 않고, 원픽에 저장된 한줄평 하나만 글로 표시한다.
- 카드 상단은 실제 등록자의 프로필 사진/사용자명을 표시한다. 게시 시각, `새로 고름 · 날짜`, `○○에서 바꿈` 같은 시간/변화 상태는 표시하지 않는다. 원픽은 게시물이 아니라 현재까지 지속되는 선택이다.
- 한줄평만 수정한 경우에는 새로 고르거나 바꾼 것으로 취급하지 않는다. 기존처럼 `started_at`을 바꾸지 않고 홈 상단으로 다시 올리지 않으며, `follow.md`의 원픽 변경 알림도 만들지 않는다.
- 카드 정보 순서는 **사람 → 채널/제공처 → 메뉴명 → 한줄평 → 원픽/댓글 지표**를 기본으로 한다. 여러 메뉴가 섞이는 목록(홈·팔로잉 피드·프로필 원픽 목록·알림)은 **A안**을 기본으로 한다: `[채널 배지][제공처]` 한 줄 → 메뉴명(메인 제목) → 한줄평. 제공처는 회색 보조 글씨가 아니라 **잉크색·보통 굵기**로 표시하고, 위치와 크기는 보조 context 수준을 유지한다. 예: `[매장] 서울집` → `미역국`, `[온라인] 99밀크티` → `클래식 밀크티`, `[레시피] 엄마의식탁` → `미역국`.
- 좋아요/하트는 두지 않는다. 좋아요 수, 인기순 피드, 반응 수 경쟁 지표도 만들지 않는다.
- `나도 이게 원픽`을 홈의 핵심 CTA로 두지 않는다. 좋아요도 두지 않는다. `✓ 내 원픽`은 **같은 item(같은 제공처·메뉴) + 같은 Pick channel**일 때만 긍정 상태로 표시하며, 다른 경우에는 아무 상태도 표시하지 않는다.
- 메뉴 이름(예: 미역국, 곱창김)을 누르면 그 메뉴를 현재 원픽으로 고른 사람들의 목록으로 이동한다. **메뉴 탐색의 제목은 `미역국`처럼 메뉴명만 유지**하고, 그 안의 개별 콘텐츠 제목만 `서울집 미역국`처럼 제공처/브랜드 + 메뉴명으로 표시한다. 메뉴 화면은 `전체 / 매장 / 온라인 / 레시피` 채널을 구분해 볼 수 있어야 한다.
- 제공처 이름을 누르면 내부 제공처 프로필로 이동한다. 오프라인 매장과 온라인 판매처는 기존 provider 기반 구조를 사용하고, 외부 링크/SNS는 제공처 프로필에서 선택적으로 노출한다.
- 외부 링크가 없으면 빈 버튼이나 `링크 없음`을 표시하지 않는다. 지도·공식몰·영상 같은 행동 링크와 Instagram·YouTube 같은 SNS는 실제 데이터가 있는 것만 표시한다.
- 원픽/한줄평 영역을 누르면 해당 원픽·상품 상세와 댓글 대화로 이동한다. 댓글은 각 한줄평에 연결되고 본인 댓글은 기존 규칙대로 삭제할 수 있다.
- 홈은 `팔로잉 / 전체` 두 범위를 유지한다. 팔로잉이 1명 이상이면 `팔로잉`, 0명이면 `전체`가 최초 기본 탭이며 상세 규칙은 `follow.md`를 따른다.
- 비로그인도 홈, 메뉴, 제공처, 공개 프로필을 둘러볼 수 있다. 원픽 저장·팔로우처럼 쓰기가 필요한 행동은 기존 로그인 복귀 의도로 연결한다.

## 메뉴 / 채널 탐색
- 메뉴는 단순 텍스트가 아니라 명확한 클릭 가능한 행으로 표시한다. 전체 행을 터치할 수 있고, 오른쪽 이동 표시와 `원픽 N` 같은 보조 지표를 둔다.
- 메뉴 상세는 사람들의 **현재 원픽**을 나열하는 화면이다. 메뉴가 화면 제목으로 이미 정해진 곳은 **D안**을 쓴다: 제공처를 크게 표시하고 메뉴 줄은 생략할 수 있다. 한 사람의 카드에는 사용자, 선택 상태, `[채널] 제공처`, 한줄평, `✓ 내 원픽 · 원픽 N · 댓글 N · 공유` 순서의 수치/행동 줄을 표시한다. `원픽 N`은 같은 콘텐츠 대상(item+channel)의 현재 active Pick 수이고, `댓글 N`은 그 카드에 표시된 사용자의 Pick 한줄평에 달린 공개 댓글 수다.
- 채널은 `전체 / 매장 / 온라인 / 레시피`로 구분한다.
  - **매장**: 지점/장소 맥락과 지도 연결이 우선이다.
  - **온라인**: 공식몰/판매처 연결이 우선이다.
  - **레시피**: 원본 영상과 제작 채널 맥락이 우선이다.
- 채널별 화면은 같은 레이아웃을 공유하되 메타 정보와 외부 연결의 의미는 채널에 맞게 바뀐다.
- 좁은 한 줄 목록(검색 결과 등)만 **B안** `[채널] 제공처 · 메뉴명`을 허용한다. 카드에는 B안을 쓰지 않는다. 제공처명이 길면 메뉴명이 잘릴 수 있기 때문이다.
- 카드 높이는 콘텐츠에 맞게 줄이고 고정된 큰 빈 여백을 만들지 않는다.

## 앱 구동 / 프런트
- HomeService → 기존 ReadRepository의 getHomePicks → home_pick_feed_page RPC → useHomeData → 홈 화면 흐름을 유지한다.
- 조회와 카드 키는 상품 ID가 아니라 Pick ID다. 같은 상품을 고른 여러 사람의 서로 다른 한줄평을 각각 보존한다.
- 로그인한 자신의 카드는 홈 둘러보기에서 제외하고 내 원픽/프로필 접근은 유지한다.
- 홈 context의 `currentPicks`를 사용해 다른 사용자의 카드가 내 현재 원픽과 같은 대상인지 판단할 수 있다. 같은 경우 `내 원픽` 표시만 추가하며 별도 쓰기 요청을 만들지 않는다.
- 계정별 people-v1 캐시로 기존 집계 상품 캐시와 분리한다. 기존 원픽/사진 작업의 home 캐시 갱신을 그대로 사용한다.
- 사진 없는 상품은 빈 이미지 플레이스홀더를 만들지 않고 텍스트가 위로 당겨지는 레이아웃을 사용한다. 기존 사진 등록 진입점은 유지한다.
- 메뉴 상세의 사용자 원픽 목록은 기존 `ReadRepository.getPicks`의 category 필터를 재사용할 수 있다. 채널 탭의 정확한 페이지네이션을 위해 앱 read input에 channel 필터를 추가하는 것은 허용하되 DB 스키마 변경은 필요하지 않다. `원픽 N`은 기존 active Pick 집계를 재사용할 수 있고, `댓글 N`을 카드마다 효율적으로 표시하려면 Pick별 댓글 count를 N+1 없이 함께 읽는 계약을 추가해야 한다.
- 제공처 프로필, 링크/SNS, 레시피 출처의 상세 데이터 계약은 `social-ui-v4.md`에서 정의한다.
- 댓글 알림 버튼, 프로필 연결, 로딩/빈 상태/다음 페이지 재시도를 유지한다.

## 백엔드 / 공개 범위
- 홈 RPC는 SECURITY INVOKER, 검색 경로 고정, 20개 + lookahead 1개. 기존 공개/차단 RLS를 적용하며 클라이언트의 로그인 세션으로 호출한다.
- active 원픽, active/discontinued 상품, 정지되지 않은 등록자, 공개·선택 가능한 말단 카테고리와 유효한 상위 카테고리만 조회한다.
- 현재 인증 사용자는 서버 auth.uid()로 결정하고 자기 원픽을 제외한다. 사용자 ID를 외부 인자로 받아 다른 계정의 피드를 가장하지 않는다.
- `started_at DESC, id DESC` 커서로 정렬과 시간 동률을 안정적으로 처리하되 그 시각을 카드에 표시하지 않는다. 한줄평 편집은 선택 시각을 바꾸지 않는다.
- 홈에서 최소 선택 인원 조건은 사용하지 않는다. 원픽 하나만 등록되어도 공개 조건에 맞으면 카드로 보여준다.
- 메뉴 랭킹에서 `최근 7일`을 실제 기준으로 사용하려면 현재 누적 `category_ranking`과 별도의 기간 필터 계약이 필요하다. UI 문구만 `최근 7일`로 바꾸지 않는다.
- 관리자 권한의 RLS 예외를 포함한 기존 정책은 바꾸지 않는다. 일반 사용자 간 차단은 DB 회귀 검사로 확인한다.

## 비목표
- 홈 좋아요/싫어요, 좋아요 수, 인기순 정렬, 추천 알고리즘.
- 타인의 원픽을 그대로 따라 고르는 것을 핵심 전환으로 만드는 CTA.
- 링크가 없는 제공처에 disabled 링크 버튼을 표시하는 것.
- 외부 링크/SNS 수를 인기 지표로 사용하는 것.

## 검증 / 배포
- 홈 서비스/화면/연속 조회 테스트를 현재 원픽 중심 계약에 맞춘다. 기존 개인정보·세션·오류 복구 검사를 유지한다.
- 홈 카드 회귀 검사에는 별도 게시물 본문 없음, 좋아요 없음, 한줄평 1개, 시간/선택 변화 문구 없음, 같은 item+channel의 `✓ 내 원픽`만 표시하는 것을 포함한다.
- 메뉴 상세은 사용자별 현재 Pick, 채널 필터, 커서 페이지네이션, 차단/정지/비공개 제외를 검증한다.
- 제공처 프로필과 외부 링크는 링크가 0개/1개/여러 개인 상태를 각각 검증하고, 유효한 https 링크만 연다.
- 마이그레이션이 필요한 항목은 Git에 준비하고 기존 배포 절차를 따른다. 운영 DB에 직접 적용하지 않는다.
