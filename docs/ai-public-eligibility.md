# AI 댓글: 공개 분석 대상 집계

## 이전 미완료 검사

`e22783f4ae15b5fa84fdf1b92d2364903c4277c9`에서 나이 검사에 빠진 한국어 조사 `으로`를 보완했다. 기존 실패를 먼저 재현하고, 정상 작품명과 명시적인 나이 표현을 요약·본문·키워드로 나눠 112개 필드 검사를 통과했다. 해당 커밋의 Mobile CI, Web build, Database Tests, AI function smoke 모두 성공을 확인했다. 문자열 검사는 모든 의미를 판별하는 품질 보증이 아니다.

## 이번 집계 변경

최소 10개 기준은 그대로 둔다. 본인의 로그인 목록 길이나 active 표시만으로 생성 자격을 표시하지 않는다.

- `profileAiEligibilityService`는 기존 세션 없는 `publicCountClient`를 사용한다. 본인/관리자에게만 보이는 정보를 집계에 포함하지 않는다.
- Edge Function과 동일하게 공개 프로필 확인 후 active 원픽, 공개 카테고리, active/discontinued 제품을 inner join으로 읽는다. 카테고리의 공개 RLS도 적용된다.
- 원픽 ID 오름차순으로 최대 50개를 읽고, ID·카테고리명·제품명·한줄평이 실제 문자열로 있는지 확인한다. 이름/한줄평은 공백을 제거한 뒤 비어 있지 않아야 한다. Edge의 buildSnapshot과 같은 필수 항목이다.
- 화면 캐시에는 숫자만 반환한다. 원픽 내용, 모델 입력, 사용자 토큰은 이 집계 캐시에 저장하지 않는다.
- 첫 생성/재평가 모두 `분석 가능한 공개 원픽 9/10개`처럼 실제 공개 조회 결과를 표시한다. 상위 프로필 목록의 개수는 조회 갱신 힌트로만 사용한다.
- 읽기 오류를 0개나 조건 충족으로 표시하지 않는다. 생성 버튼을 막고 `원픽 수 다시 확인`을 제공한다. 초기 확인 중 상태도 구분한다.
- 생성 클릭 시 연결 상태와 공개 개수를 다시 확인한다. 10개 미만, 조회 실패, 잘못된 숫자라면 모델 생성 요청을 보내지 않는다. 서버도 기존대로 다시 집계하고 최종 판단한다.
- 데이터가 확인 직후 달라질 가능성은 남으므로, 이 사전 확인을 서버 권한/개수 검사의 대체물로 사용하지 않는다. 서버가 원픽 부족이나 원본 변경을 반환하면 공개 개수를 다시 조회한다.
- 집계는 본인 프로필에서만 활성화하며 30초 전경 갱신과 화면 해제 시 취소를 지원한다. 두 조회 전체에 8초 제한을 둔다. 최대 50개라는 현재 서버 입력 한도를 전체 원픽 수로 혼동하지 않는다.
- 집계 오류/대기/10개 미만은 기존 댓글의 공개·숨김 권한과 분리한다. 특히 숨기기는 계속 가능하다. 기존 공개 버전 비교와 계정 전환 보호는 유지한다.

## 검증

`test-profile-ai-eligibility.cjs`는 실제 집계 서비스·카드·훅을 모의 DB/React Query 응답으로 실행한다. 로컬에서 41개 검사를 통과했다. 공개 9개+비공개 1개, 승인 대기/숨김 제품, 이전 선택, 읽을 수 없는 관계, 공백 한줄평, 단종 제품, 50개 한도, 조회 오류/취소/지연, 부모 목록과의 개수 차이, 클릭 직전 감소, 잘못된 응답, 공개/숨김 유지 등을 포함한다.

기존 최소 개수/공개 버튼 테스트에는 집계 훅의 응답만 추가하고 기존 단언은 유지한다. 이번 최종 커밋의 전체 CI 결과는 별도 확인한다. 이전 커밋의 성공을 새 변경의 성공으로 간주하지 않는다.

## 반영 범위와 남은 조건

개발 브랜치 코드와 검사만 변경한다. 원격 DB 쓰기, API 키 등록, 실제 모델 생성, 사용자 평가 게시, 서버/앱 배포 및 main 병합은 하지 않는다. 기존 배포 서버가 최신 브랜치와 다르다는 점은 계속 유효하다. 실제 로그인 브라우저와 모델 문장 품질의 검증도 별도 필요하다.

주류를 고르지 않아도 10개를 채울 수 있는 카테고리 구성과 실패 후 재요청 정책은 이번 변경에서 바꾸지 않았다. 나이 표현 제외, 공격적이지 않은 말투, 선택과 한줄평 중심의 해석, 등록 안내 문구는 유지한다.
