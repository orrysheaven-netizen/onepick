# MVP 콘텐츠 시딩 운영 기준

## 목적

초기 OnePick에서 "사람마다 하나를 고르고, 그 이유가 서로 다르다"는 핵심 가치를 실제 데이터로 보여준다.
가짜 사용자나 운영자가 만든 가상의 취향을 사용하지 않고, 실제 베타 테스터가 직접 선택한 원픽만 시딩 데이터로 인정한다.

## 1차 목표

- 공개 프로필: 최소 5개
- 실제 사용자 원픽: 최소 15개
- 1인당: 서로 다른 카테고리 3개 이상
- 핵심 카테고리 4개 이상에서:
  - 선택 사용자 3명 이상
  - 서로 다른 아이템 2개 이상
- 한줄평은 사용자가 직접 작성한 문장만 사용

## 초기 테스트 카테고리

우선 다음과 같이 일상적인 카테고리를 중심으로 진행한다.

- 라면
- 영화
- 드라마
- 포켓몬
- 음악
- 유튜브
- 과자

게임처럼 아직 선택 데이터가 없는 카테고리는 실제 테스터가 자연스럽게 선택하기 전까지 시딩 목표에서 제외해도 된다.

## 운영 원칙

1. 가짜 계정을 여러 개 만들어 선택 수를 부풀리지 않는다.
2. 운영자가 테스트 계정으로 다른 사람의 취향을 대신 만들지 않는다.
3. 서로 같은 제품을 고르게 유도하지 않는다.
4. 한줄평 예시를 복사하게 하지 않는다.
5. 사진이 없어도 원픽 선택 자체를 막지 않는다.
6. 첫 라운드는 콘텐츠 수보다 서로 다른 사람의 선택과 이유가 보이는지 확인한다.

## 확인 지표

1차 시딩 후 아래를 확인한다.

- 홈에서 여러 사용자명이 반복 없이 자연스럽게 보이는가
- 같은 카테고리에서 서로 다른 제품 선택이 보이는가
- 제품 상세에서 다른 사람의 한줄평을 비교할 수 있는가
- 공개 프로필마다 최소 3개의 원픽이 보이는가
- 공유 링크에서 해당 사용자의 원픽 맥락이 유지되는가

## 완료 기준

아래를 모두 만족하면 1차 콘텐츠 시딩을 완료한 것으로 본다.

- 실제 사용자 5명 이상
- 공개 원픽 15개 이상
- 핵심 카테고리 4개 이상에 사용자 선택이 분산
- 홈 첫 화면에서 최소 3명의 서로 다른 사용자 맥락 확인
- QA 계정이 홈 콘텐츠 대부분을 차지하지 않음
