# OnePick AI 취향평가

## 목적

프로필의 공개 원픽과 한줄평만 바탕으로 “내 취향이 곧 나이다.”라는 컨셉의 AI 취향 해석을 제공한다.

## 작성자

- 시스템 작성자: `OnePick AI`
- DB: `public.system_actors`
- 로그인 가능한 일반 사용자 계정이 아니다.
- 클라이언트는 시스템 작성자를 사칭해 평가를 만들거나 수정할 수 없다.

## 저장

- 최신 평가: `public.profile_ai_reviews`
- 사용자는 자신의 평가 공개 여부(`is_visible`)만 바꿀 수 있다.
- 평가 본문, 키워드, 모델 정보, 원픽 스냅샷은 서버에서만 작성한다.
- 공개 클라이언트에는 원픽 스냅샷과 내부 모델 메타데이터를 노출하지 않는다.

## 생성 규칙

- 공개/현재 원픽이 최소 3개 필요하다.
- 같은 원픽 상태에서는 기존 평가를 재사용한다.
- 원픽이 바뀐 뒤 재평가에는 10분 쿨다운을 둔다.
- 모델: `gpt-5.6-terra`
- OpenAI Responses API 호출은 `store: false`로 설정해 응답 객체 저장을 비활성화한다.
- 프롬프트 버전: `taste-v1`

## 안전 기준

AI는 취향 패턴만 해석한다. 건강, 정신건강, 장애, 인종·민족, 국적, 종교, 정치성향, 성적 지향/성생활, 경제상태, 범죄이력, 지능, 진단 등 민감한 개인 특성을 원픽에서 추론하지 않는다. 성격을 단정하지 않고 선택에서 관찰되는 경향으로 표현한다.

## 서버 설정

Edge Function `analyze-profile-taste`는 인증된 사용자만 호출한다. OpenAI 비밀키는 앱 코드에 넣지 않고 Supabase Edge Function Secret의 `OPENAI_API_KEY`로만 제공한다.

비밀키가 등록되기 전에는 함수를 배포/활성화하지 않는다.
