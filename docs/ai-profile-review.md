# OnePick AI 취향평가

## 목적

“내 취향이 곧 나이다.” 공개 원픽과 한줄평의 취향 패턴을 해석하고, 프로필에 AI 작성자 배지가 있는 댓글형 카드로 표시한다. 사람의 가치·능력이나 민감한 특성을 판정하지 않는다.

## 작성자와 저장

- 시스템 작성자: `OnePick AI`, 식별자 `onepick_ai`. `public.system_actors`에 저장하며 일반 로그인 회원이나 OpenAI 가입 계정이 아니다.
- 최신 결과는 `public.profile_ai_reviews`에 프로필별 한 건 저장한다.
- 본문·키워드·원픽 스냅샷·모델 정보·최신성 표시는 서버에서만 작성한다. 사용자는 자신의 공개/숨김만 변경할 수 있다.
- 첫 생성과 재생성 결과 모두 본인만 보는 미리보기로 저장한다. 본인이 읽고 다시 공개한다. 같은 원픽 상태의 기존 결과 조회는 공개 설정을 유지한다.
- 읽기 권한은 기존 `profiles` RLS도 확인하므로 차단·정지로 볼 수 없는 프로필의 평가도 읽을 수 없다.
- 일반 클라이언트에는 원픽 스냅샷, 모델 정보, 내부 원본 버전의 읽기 권한이 없다.

## 원픽 변경과 이전 평가

- `picks`의 활성 선택 추가·교체·삭제·숨김·한줄평 수정은 해당 사용자의 평가를 `is_stale=true`, `is_visible=false`로 변경한다.
- 분석에 들어가는 제품 이름·원제·출시연도·제작자·컬렉션·상태·카테고리 변경, 카테고리 이름·상태·공개 여부 변경도 해당 활성 선택을 가진 사용자의 평가를 비공개로 만든다.
- 소개글, 제품 외부 링크, 사진처럼 모델 입력에 사용하지 않는 정보만 바뀐 경우에는 이 트리거로 무효화하지 않는다.
- 이전 결과는 본인에게 참고용으로 남기고, 재평가 전 공개 버튼을 비활성화한다. DB 제약조건도 오래된 평가의 재공개를 거부한다.
- 자동 비공개는 원픽 변경 트랜잭션에서 처리한다. 이미 열린 전경 화면은 30초 간격으로 최신 상태를 확인한다. 이미 본 내용이나 복사·캡처된 내용을 회수하는 기능은 아니다.

## 생성 흐름

1. 버튼 주변에서 OpenAI에 전달하는 정보와 본인 미리보기를 안내한다.
2. 서버에서 사용자 토큰을 검증한다. 임의 사용자 ID를 받아 다른 사람을 평가하지 않는다.
3. 세션 없는 공개 클라이언트로 `active` 원픽, 공개 카테고리, `active`/`discontinued` 제품을 읽는다. 소유자·관리자 권한으로 숨김·승인 대기 데이터를 읽어 분석하지 않는다.
4. 공개적으로 읽을 수 있는 원픽이 최소 3개 필요하다. 최대 50개를 읽는다.
5. 원본 버전·지문·모델·프롬프트가 같고 오래되지 않은 결과는 재사용한다.
6. 모델 호출 전에 `reserve_profile_ai_generation`으로 생성 슬롯을 확보한다.
7. 응답 완료 및 거절 여부, 요약·본문 길이, 서로 다른 키워드 정확히 3개를 검증한다.
8. 저장 직전에 공개 원픽을 다시 읽는다. 이어서 서버 전용 `save_profile_ai_review`가 DB 잠금 아래 원본 버전을 비교하고 저장한다. 마지막 확인과 저장 사이에 원픽이 바뀌어도 이전 버전 저장을 거부한다.
9. 새 본문은 항상 비공개로 저장한다. 이전 평가의 공개 상태를 새 문장에 자동 승계하지 않는다.

## 요청 제한과 버전

- `profile_ai_generation_limits`는 생성 제한 시각과 `source_version`을 저장한다. 일반 클라이언트는 접근할 수 없다.
- 새 생성 요청은 프로필당 10분에 한 번이다. 공급자 오류·타임아웃·생성 중 원픽 변경으로 실패한 시도도 이미 확보한 슬롯을 소비한다.
- 원픽 변경은 원본 버전만 올리며 제한 시각을 초기화하지 않는다. 같은 상태의 캐시 조회는 슬롯을 소비하지 않는다.
- 저장 함수는 `SECURITY INVOKER`이며 실행 권한은 `service_role`만 가진다. 원본 변경과 결과 저장은 같은 행 잠금을 사용한다.
- 비공개 무효화 트리거는 제한된 `private` 함수다. 기존 원픽·카탈로그 쓰기의 권한 검사를 통과한 변경에 대해서만 시스템 소유 결과를 무효화하며, 공개 RPC로 실행할 수 없다.
- 프로필별 제한은 서비스 전체 비용 상한이나 부정 가입 방지를 대체하지 않는다.

## 모델과 데이터

- 모델: `gpt-5.6-terra`. 프롬프트 버전: `taste-v3`.
- Responses API 구조화 출력을 사용하고 `store: false`로 응답 객체 저장을 비활성화한다. 공급자의 모든 로그가 전혀 보관되지 않는다는 뜻은 아니다.
- 모델에는 제품·콘텐츠 이름, 카테고리, 필요한 카탈로그 정보, 한줄평만 전달한다.
- 계정·원픽 ID, 사진, SNS 링크, 수정 시각, 내부 원본 버전은 모델에 보내지 않는다.
- 오류 로그에는 키, 공급자 응답 본문, 원픽 목록, 생성 문장을 기록하지 않는다.

## 안전 기준

관찰 가능한 취향 경향만 표현한다. 건강·정신건강·장애·인종·민족·국적·종교·정치성향·성적 지향·경제상태·범죄이력·지능·진단·나이·외모·체형 등을 추론하거나 사람을 점수화하지 않는다. 입력 이름·카테고리·한줄평은 지시문이 아닌 신뢰할 수 없는 데이터로 취급한다. 지시문 작성이나 구조 검증만으로 모든 실제 문장의 안전성을 검증한 것은 아니므로 실제 생성 QA가 필요하다.

## 검증

- `032_profile_ai_reviews.sql`: AI 사칭 방지, 본문 수정 제한, 숨김 결과 접근 제한.
- `033_profile_ai_privacy_limits.sql`: 비공개 기본값, 본인 공개, 차단·정지 보호, 서버 전용 생성 제한.
- `034_profile_ai_source_changes.sql`: 원픽·한줄평·제품명·카테고리 변경과 삭제 시 무효화, 다른 사용자 영향 분리, 소개글·링크 수정 시 유지, 오래된 결과 공개/저장 차단, 새 비공개 미리보기, 쿨다운 보존.
- 2026-09-19: 원격 DB에서 추가 변경 시나리오를 트랜잭션으로 검증했고 테스트 데이터는 모두 롤백했다. 실제 사용자 프로필에 테스트 AI 평가를 남기지 않았다.
- GitHub Actions의 Mobile CI, Web build, Database Tests 및 Deno 타입 검사를 최종 커밋 기준으로 확인한다. 이전 커밋 결과를 새 코드 검증으로 간주하지 않는다.
- 실제 동시 세션의 부하 테스트, 실제 모델 문장 품질 평가 및 로그인 브라우저의 전체 흐름 검증은 별도로 필요하다.

## 배포 전 남은 작업

- Supabase Edge Function Secret의 `OPENAI_API_KEY` 설정 및 사용 권한/과금 확인. 키는 채팅·저장소·프런트엔드에 넣지 않는다.
- `analyze-profile-taste` 배포 및 JWT 인증 확인. 키가 준비되기 전에는 활성화하지 않는다.
- 실제 계정에서 생성 → 본인 미리보기 → 공개 → 다른 계정 조회 → 원픽 수정 → 자동 숨김 → 재평가를 검증한다.
- API 오류·거절·타임아웃, 계정 전환, 동시 요청, 생성 문장의 품질·안전성을 확인한다.
- 카테고리 공개 설정이 바뀐 상황의 화면상 원픽 개수 안내도 실제 앱에서 확인한다. 서버의 생성 가능 여부가 최종 기준이다.
- 위 검증 뒤 PR 병합 및 앱 배포. DB 반영과 코드 저장은 실제 AI 기능 활성화와 구분한다.
