# 배포 전 안정화: 영화 선택과 로그인 복귀

## 이번 범위
기존 영화 검색/선택 경로의 실패 복구를 보완한다. 새로운 기능이나 사이트를 추가하지 않는다. 영화 선택은 상품 카탈로그 정보를 준비한 뒤 기존 한줄평 화면으로 이동하는 과정이며 원픽을 자동 저장하지 않는다.

## 수정 사항
- 로그인 복귀 후 선택한 영화의 정보를 불러오는 데 실패하면 `선택한 영화 다시 불러오기`로 같은 영화 ID를 명시적으로 재시도한다. 렌더링마다 자동 재요청하지 않는다.
- mutation 상태가 반영되기 전 빠른 연속 탭도 동기적으로 잠근다. 완료 직전의 오래된 버튼 핸들러가 재요청하거나 같은 화면을 두 번 쌓지 못하게 한다.
- Expo SDK 57의 useFocusEffect 정리 동작과 요청 세대 번호로 뒤로가기·화면 이탈·언마운트 이후의 늦은 응답이 다른 화면을 이동시키지 못하게 한다. 서버에서 시작한 카탈로그 작업을 취소했다고 주장하지 않는다. 다시 돌아오면 명시적으로 이어갈 수 있다.
- 계정·카테고리·복귀 영화·전달 검색어가 달라지면 폼을 새로 생성한다. 같은 계정의 일시적인 인증 확인 실패 중 성공한 결과는 보관하고 복구 후 `선택한 영화로 계속`을 제공한다.
- 인증 확인 중/실패 시 검색 결과·선택 입력을 노출하지 않는다. 실제 인증 만료 응답은 일반 통신 실패가 아니라 AUTH_REQUIRED로 분류하고 기존 choose_movie 로그인 복귀 의도를 유지한다.
- 영화가 아닌 카테고리의 복귀 링크, 배열형/잘못된 외부 ID는 자동 가져오기를 실행하지 않는다. 응답 카테고리가 요청 카테고리와 다르면 잘못된 원픽 화면으로 이동하지 않는다.
- 외부 영화 검색어는 서버의 기존 2~60자 조건에 맞춰 조회한다. 60자를 넘기면 설명을 표시하고 기존 등록 상품 검색은 계속 제공한다.
- 오류 응답은 알려진 코드만 구분한다. 인증 만료, 요청 제한, 사용할 수 없는 영화, 카테고리 오류를 구분하고 임의의 서버 메시지를 사용자에게 표시하지 않는다. 원본 응답을 소비하지 않도록 clone을 사용한다.
- 오래되거나 실패한 카테고리/검색 응답에서 선택 가능한 카드가 남지 않게 한다. 이미 등록된 영화는 기존 상품 선택 경로를 재사용한다.

## 검증
- test-movie-selection-recovery.cjs를 먼저 커밋하여 기존 코드에서 실패 상황을 검사한다. 10개 그룹에서 로그인 복귀 재시도, 중복 탭, 뒤로가기/초점 해제/계정 전환, 입력 검증, 응답 카테고리, 인증 재확인, 오류 분류 및 검색 길이 조건을 다룬다.
- test-find-movie-search.cjs는 새 런타임 의존성(useFocusEffect, AppError)의 모의 구현만 추가한다. 기존 검색/카테고리 동작 검사는 유지한다.
- 검사는 실제 소스를 변환한 결정적 훅/컴포넌트 실행 및 저장 계층 모의 검사다. 실제 카카오 OAuth, TMDB 연결, 물리적 휴대폰이나 브라우저 DOM 종단 간 검사로 간주하지 않는다.

## 배포 보류
같은 PR #11과 작업 브랜치에 누적한다. main 병합, Cloudflare/Vercel 배포, 운영 DB·데이터·인증 설정 변경 및 의존성 변경은 하지 않는다. 기존 사진 등록, 자기소개, 사람 중심 홈과 이전 안정화 작업을 유지한다.

실제 운영 주소 단일화, 두 계정의 모바일 사용 검증, 공용 사진 오류 신고/관리자 정정, 의존성 보안 경고 검토는 아직 별도 완료 조건이다. 이번 변경을 해당 항목의 완료로 간주하지 않는다.
