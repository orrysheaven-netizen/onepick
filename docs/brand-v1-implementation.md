# OnePick 브랜드 v1 — 적용 초안과 검증 경계

Refs #303. Owner: codex. Size: M. Area: frontend.

## 이번 변경

- 지시서에 실제 포함된 확정 SVG는 6개다. 가로/흰색 가로/세로 로고와 밝은/어두운 앱 아이콘, 파비콘 원본을 변경 없이 저장했다. 회귀 테스트가 기존 원본 SHA-256을 고정한다.
- 가로 헤더는 24/28px 높이와 원본 비율을 유지한다. 바깥 여백은 표시된 점의 지름 이상이며 홈 링크에는 접근성 이름이 있다. 흰색 가로 로고는 `appearance="dark"`로 명시적으로 선택한다. 앱 전체 다크 모드를 새로 도입하지 않는다.
- 앱 아이콘 원본에서 불투명 180/192/512 PNG를 만들었다. 180은 Apple Touch, 192/512는 웹 매니페스트에 연결한다. 기존 네이티브 앱 아이콘 설정은 보존한다. 파비콘 ICO에는 16/32/48px가 들어 있다.
- 기존 OG 메타데이터와 앱 플러그인/인증/기능 플래그를 보존한다. 스플래시와 OG 이미지 자체는 이번 범위 밖이다.
- 페이퍼/잉크/그레이와 `brand`/`onBrand`, Outfit/IBM Plex Sans KR 글꼴 토큰을 추가한다. 기존 `accent`는 작은 링크와 채움색을 겸하므로 일괄 탠저린 치환 대신 잉크로 유지한다. 탠저린 위 글자는 잉크다.

## 완료로 간주하지 않은 항목

1. **실제 본문 글꼴 로딩**: 현재는 토큰과 fallback만 있다. Google Fonts 외부 stylesheet/font 요청은 기존 `style-src 'self'` 및 `font-src 'self' data:` 정책과 맞지 않으므로 넣지 않았다. 동일 출처 웹폰트 제공과 라이선스 보존을 추가 구현·검증해야 한다. 로고는 path이므로 이에 영향받지 않는다.
2. **컴포넌트별 강조색 전환**: 버튼·선택 표시를 `brand`/`onBrand`로 함께 바꾸고 텍스트 대비와 기존 UI 테스트를 검증하는 후속 diff가 필요하다. 작은 글자까지 주황색으로 바꾸지 않는다.
3. **실제 앱/기기 검증**: 실행 중인 앱의 헤더 배치·접근성, 브라우저 탭, iPhone 홈 화면 추가, 네이티브 아이콘 빌드는 아직 확인하지 않았다. 자산 렌더링은 실제 앱 화면 검증을 대신하지 않는다.
4. 필수 `typecheck`, `verify-web`, `database-tests`와 Claude 독립 리뷰 결과를 PR에서 확인한 뒤에만 준비 완료로 전환한다. 이 문서는 병합 승인이 아니다.

## 재현 가능한 검사

`cd mobile && node scripts/test-brand-assets.cjs`

기존 `scripts/run-tests.cjs`가 `test-*.cjs`를 자동 수집하므로 새 workflow 없이 회귀 검사에 포함된다. 이 검사는 원본 해시·파일 구조·연결을 검사하며 실제 앱 UI나 글꼴 다운로드를 시험하지 않는다.

## 변경하지 않는 보호 영역

DB, Auth, RLS, Storage, CSP/보안 헤더, secrets, CI workflow, 배포 설정은 수정하지 않는다. main 직접 쓰기, 운영 데이터 변경 및 자동 병합은 하지 않는다.
