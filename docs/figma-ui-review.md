# Figma UI 리뷰 로그 (클로드 · UI/UX)

클로드는 피그마를 직접 고치지 않고, 변경 사항을 점검해 방향과 개선안을 이 문서에 남깁니다. 현재 UI 안정화 단계라 **새 화면 추가는 제안하지 않고** 기존 화면의 KEEP / UPDATE / MERGE / DELETE 판정과 Foundations 통일만 다룹니다.

스냅샷: `docs/figma-snapshots/<날짜>-social-ui.tsv` (최상위 프레임별 노드 수·인스턴스 수). 다음 점검에서 이 파일과 비교해 추가·삭제·이름 변경·크게 바뀐 프레임을 찾습니다.

### 공통으로 보이는 문제

1. **상단 헤더 겹침(시각 버그).** 30-1·31-1은 입력칸이 로고 위로 올라가 주황 테마 버튼 일부만 보이고, 30-2·40-1은 제목(`사람들의 원픽`, `duck`)이 로고·통계와 겹칩니다. `App Header`(56) 인스턴스를 맨 위에 두고 그 아래부터 콘텐츠를 쌓아야 합니다.
2. **하단 탭 크기 불일치.** 같은 화면 묶음 안에서도 `+` 버튼 지름(약 40 vs 48)과 라벨 위치가 다릅니다. 모두 `Tab Bar` 인스턴스로 교체하면 한 번에 해결됩니다.
3. **빈 썸네일.** 홈 피드·프로필 원픽 목록에 베이지/파랑/분홍 빈 사각형이 있습니다. `social-ui-v4.md`는 “사진이 없으면 빈 이미지 영역을 만들지 않는다”이고, Foundations는 사진 없는 썸네일을 `bg/placeholder` 한 가지로만 허용합니다. 둘 중 하나로 정해야 합니다 → **제안: 피드 카드는 사진 없으면 영역 제거, 목록 행(36 썸네일)만 `bg/placeholder`.**
4. **집계 표기 혼용.** 홈은 `원픽 23`, 탐색·프로필은 `31명`·`원픽 12`. OnePick 언어 원칙대로 `원픽 N`으로 통일 제안.
5. **채널 태그 색.** `매장` 태그가 베이지·파랑 두 종류로 섞여 있습니다. `Tag / Soft` 하나로 통일.

### 화면별 개선안

**30 홈**
- 30-3(“다음 검토 · 탐색 — 메뉴별 원픽”)은 31-1과 같은 화면입니다 → 30에서 제거(MERGE into 31).
- 메뉴 그리드는 `Section Header` + `Chip` + `Menu Tile`, 피드는 `Feed Card`로 교체.
- 30-1 아래 “사람들의 원픽” 미리보기와 30-2 피드는 같은 스크롤의 위/아래입니다. 30-2 상단의 겹친 제목을 `Section Header`로 바꾸고 App Header는 스크롤 시 고정 여부를 한 번만 명시.

**31 탐색**
- 설명문은 “초기 MVP는 온라인·레시피 채널 선택을 노출하지 않는다”인데 30-3에는 `매장/온라인/레시피` 칩이 있습니다. MVP 기준 화면에서는 채널 칩을 빼고, 31-2·31-3처럼 `후속` 표기가 된 곳에만 둡니다.
- 행 전체가 눌려야 한다는 v4 원칙과 달리 지금은 `라멘집 ›`처럼 이름 옆 작은 chevron만 있습니다. `List Row`로 바꾸고 chevron은 행 오른쪽 끝, 숫자는 그 왼쪽에 정렬(현재는 행 가운데쯤 떠 있음).
- `가나다순 ▾`은 텍스트만 있어 눌리는지 약합니다 → `Button / Text` + ▾ 로 교체.

**75 원픽 등록 v6** (기준 화면, 유지)
- 75-1 결과 카드의 “상세 주소 표시 ›”는 누르면 무엇이 되는지 불분명합니다. 결과 카드를 누르면 선택, 주소는 보조 정보(Caption)로만 두는 편이 명확합니다.
- 75-5의 “맞는 카테고리가 없어요”는 관리자 요청으로 이어지는 마지막 선택지인데 일반 텍스트처럼 보입니다 → `Button / Text`.
- 75-7 완료 Dialog는 Foundations 정의상 `Toast`(짧은 완료 알림)와 겹칩니다. 저장 후 이어지는 행동이 “확인” 하나뿐이면 Toast + 이전 화면 복귀가 더 가볍습니다. 기능 흐름 변경이므로 **사용자 결정 필요**.

**40 다른 사용자 프로필**
- 40-1(통계 2개: 원픽·댓글) / 40-2(원픽·팔로워·팔로잉) / 40-3(한 줄 요약)이 서로 다른 헤더를 씁니다. `Profile Header` 하나로 통일하고 팔로우 전/후는 버튼 상태만 다르게.
- 40-3 로그인 시트는 공용 원칙 6항(비로그인 팔로우 → 로그인 → 복귀 → 자동 팔로우 → 토스트)을 잘 담고 있습니다. 이 시트가 78번 흐름의 대체이므로 78번 제거 조건 충족으로 봐도 됩니다(현재 파일에 78번 프레임 없음 — 이미 정리됨).

**39 알림**
- 왼쪽 목업이 알림 목록이 아니라 홈 피드이고, 탭 점만 알림에 있습니다. “새 알림 점이 모든 탭 화면에서 같은 위치에 뜬다”를 보여주려는 의도라면 캡션을 붙이고, 아니라면 제거.
- 오른쪽 목록은 `Notification Row`로 교체. 행 배경이 옅은 노랑(안 읽음 표시로 보임)인데 Foundations 규칙은 “안 읽음은 탠저린 점”이므로 배경색은 제거.
