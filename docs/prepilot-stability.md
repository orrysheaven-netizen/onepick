# 소수 배포 전 안정화 — 저장과 댓글 복구

## 범위
새 기능/사이트/DB를 만들지 않고 기존 PR #11에서 사용 오류를 재현하고 수정한다. Cloudflare 연결 및 단일 사이트 배포 보류는 그대로 유지한다. 오류가 전혀 없거나 실제 기기 검증까지 마쳤다고 주장하지 않는다.

## 이번 재현과 수정
- 원픽 선택: mutation의 isPending이 화면에 반영되기 전 연속 두 번 누르면 저장 요청이 두 번 발생했다. 동기적인 idle/saving/saved 단계로 중복 요청을 차단한다. 확인된 저장의 이전 이벤트 핸들러도 재저장하지 않는다. 실패한 요청은 idle로 돌아가 같은 초안을 재시도할 수 있다.
- 저장 중 한줄평 편집과 앱의 뒤로가기 버튼을 막아 전송된 내용과 화면 내용이 어긋나는 상황을 줄인다. 브라우저 닫기, OS 뒤로가기, 다른 탭 이동을 모두 차단하는 기능은 아니다.
- 상품 조회 실패: 뒤로가기만 있던 원픽 선택 오류 화면에 조회 재시도를 추가한다. 이미 조회 중이면 다시 요청하지 않는다. 같은 폼에서 다시 불러오면 작성했던 이유가 유지된다. 새로고침/앱 종료 후 초안 복원은 포함하지 않는다.
- 직접 진입: 이전 앱 화면이 없는 원픽 선택 화면에서 뒤로가기 버튼은 홈으로 이동한다. 기존 정상 탐색에서는 실제 뒤로가기를 유지한다.
- 댓글 세션: 로그인 확인 중이거나 실패한 동안 저장된 댓글 목록과 입력기를 숨기고 확인 재시도를 제공한다. 댓글 조회도 확인이 끝날 때까지 비활성화한다.
- 댓글 캐시: 사용자별 표시 범위가 다른데 Pick ID만 캐시 키로 사용하던 부분을 방문자별로 분리한다. 기존 comments/pick/ID 접두사를 유지하여 새 댓글 후 전체 관련 캐시 갱신은 그대로 동작한다. 이 수정은 캐시 격리 보완이며 실제 운영 환경에서 정보 노출이 발생했다고 확인한 것은 아니다.
- 댓글 초안: 계정/Pick 변경 시 댓글 폼을 새로 생성한다. 이전 폼의 늦은 저장 결과가 새 계정/다른 댓글창의 초안을 지우지 않는다. 일시적인 같은 계정의 세션 오류 후에는 기존 초안을 유지한다.
- 댓글 페이지 중복을 댓글 ID로 제거하고, 불러오기 실패를 빈 댓글 목록과 동시에 표시하지 않는다.

## 재현 테스트
`mobile/scripts/test-prepilot-recovery.cjs`를 먼저 추가했다. 수정 전 테스트 전용 커밋 e100f6266d4e4dd7fbb97df87bce8c114c3dd999의 Mobile CI #675에서 7개 중 6개 검사가 실패했고, 원래의 38개 회귀 스크립트는 통과했다. 실패 로그에는 동일 프레임 저장 요청 2회, 조회 재시도 버튼 부재, 직접 진입 뒤로가기, 댓글 사용자 캐시 공용, 세션 확인 중 캐시 표시, 계정 전환 후 댓글 초안 유지가 확인된다.

새 검사는 실제 소스의 JSX를 변환하여 결정적인 훅/컴포넌트 실행기로 실행한다. refs를 렌더 간 유지하고 JSX 키별 초안을 분리해 기존 단순 렌더 검사에서 놓친 경계를 검사한다. 브라우저 DOM, 실제 터치, 네이티브 키보드 또는 네트워크 종단 간 테스트가 아니다. 테스트를 약하게 바꾸지 않고 실제 소스를 수정한 뒤 같은 검사를 다시 실행한다.

## 배포 전 남은 필수 확인
- 기존 운영 주소 하나에 검증된 코드와 보류 중 마이그레이션이 함께 반영되는지 확인.
- 실제 두 계정으로 둘러보기 → 같은/다른 원픽 등록 → 저장 결과 확인 → 댓글/알림까지 실행.
- iPhone/Android에서 로그인 복귀, 사진 선택/취소/업로드, 키보드와 저장 버튼, 느린 네트워크/실패 후 재시도 확인.
- 공용 사진의 오류 신고/관리자 정정 경로, 의존성 취약점 경고 영향 분석은 아직 별도 점검 필요.
- 최초 사용자명 미설정/로그인 만료 후 모든 입력 경로의 복귀, 사진 업로드 후 조회 실패 및 앱 종료 중 초안 처리도 후속 검증 대상으로 유지.

## 운영 변경 여부
이번 수정에는 DB, 사용자 데이터, 의존성, 인증 권한, 호스팅 설정 변경이 없다. 기존 작업 브랜치에만 저장하고 main에 병합하거나 운영 배포하지 않는다. 이전 사진 등록, 자기소개, 사람 중심 홈, 저장 결과 확인 기능을 유지한다.
