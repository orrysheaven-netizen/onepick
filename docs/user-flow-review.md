# 사용자 흐름 점검

## 확인 범위

- 2026-09-17, 로컬 웹 실행본과 feature/pick-core 코드 기준.
- 기존 자동 검사 22개 통과. 웹 release 검사는 Windows 하위 프로세스 제한 때문에 별도 실행하여 통과.
- 발견한 관리자 후보 오류 회귀 검사 추가 및 통과. 타입 검사와 웹 빌드 통과.
- 브라우저: 신라면 검색 → 기존 원픽 한줄평 수정 화면, 미등록 검색 → 이름을 유지한 등록 요청 화면 확인.
- 실제 사용자 요청 생성·승인·원픽 변경·삭제는 이번 점검에서 실행하지 않았다. 저장·동시 입력·실패 복구는 기존 자동 검사로 확인했다. 새 사용자/다른 계정, 실제 모바일, 사진 업로드를 포함한 전체 실사용 검증은 별도로 필요하다.

## 수정한 오류

관리자 등록 요청 화면에서 기존 제품 후보를 찾을 때 후보를 요청 제품과 비교하지 않고 자기 자신과 비교했다. `id !== id` 조건 때문에 후보가 항상 비어 있었다. 요청 제품과 후보를 분리하여 같은 카테고리의 활성·단종 제품만 후보로 표시하고, 이름 일치 → 부분 일치 순으로 정렬하도록 수정했다. 최대 3개 표시한다. 최종 연결은 관리자가 판단한다.

## 남은 개선 사항

1. **분류 없는 등록 요청**: 현재 실행본은 카테고리가 필수다. 원하는 분류가 없는 영화 등의 요청이 막힐 수 있다. 사용자는 이름·사진만 제출하고 관리자가 분류하는 변경을 준비했지만 원격 DB 적용 승인 대기 중이다. 현재 배포에는 포함하지 않았다.
2. **상품 한줄평 더 보기**: 내 현재 한줄평은 별도 조회하여 최상단에 표시되지만 타인의 한줄평은 최근 20개까지만 조회한다. 선택 인원은 정확한 전체 공개 집계이므로, 인원과 보이는 한줄평 수가 다를 수 있다. 페이지 추가 조회가 필요하다.
3. **등록 경로 통일**: 검색 결과는 `/pick/choose`, 상품 상세는 `/pick/register`로 연결된다. 같은 원픽 저장 기능의 입력 화면이 달라 사진과 안내 경험에 차이가 있다. 공통 입력 화면으로 통일하는 것이 좋다.
4. **사진 가져오기 안내**: 제조사 허용 목록과 JPG/PNG 등 지원 제한이 있다. 일반 검색 결과 링크나 영화 이미지 링크는 지원되지 않을 수 있다. 실패 시 직접 사진 선택으로 이어지는 안내를 더 구체화하는 것이 좋다.

## 출시 전 실제 사용 검증

별도 테스트 계정 두 개로 신규 요청 → 승인/기존 제품 연결 → 원픽 저장 → 다른 사용자 상품 페이지 → 댓글/한줄평 → 원픽 변경 → 공유 링크를 확인한다. iPhone Safari에서 로그인 복귀와 사진 선택도 검증한다. 현재 사용자의 선택 기록을 테스트 목적으로 덮어쓰지 않는다.
