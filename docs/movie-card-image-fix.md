# 영화 카드 이미지 누락 수정

## 원인
- 영화 상세 및 프로필은 `items.image_source_url`의 외부 포스터 주소를 사용했다.
- 탐색 TOP 3 조회는 `thumbnail_path`만 반환했고, 홈 조회는 업로드 이미지 경로만 반환했다.
- 따라서 저장소에 업로드한 사진 없이 외부 포스터만 있는 영화는 카드에서 `사진 없음`으로 표시됐다.

## 변경
- TOP 3 응답에 `image_path`, `image_source_url` 필드를 추가했다. 기존 여섯 필드는 동일하게 유지한다.
- 홈 페이지 조회와 기존 홈 조회의 JSON에 `image_source_url`을 추가했다.
- 카드 표시 우선순위: 업로드 썸네일 → 업로드 원본 → 외부 포스터 → 사진 없음.
- 외부 포스터 주소는 Storage 경로로 변환하지 않는다.
- 제품 상세/프로필 mapper에도 업로드 원본 fallback을 유지해 같은 우선순위를 적용한다.
- 사용자 데이터, 선택 수, 공동 순위, 사진 업로드 제약, RLS, 홈 페이지 커서 및 프로필 정보는 바꾸지 않는다.

## 검증
- `mobile/scripts/test-catalog-card-images.cjs`: 영화 포스터, 업로드 우선, 원본 fallback, 사진 없음, 홈 페이지 커서, 오류 및 실제 Image 컴포넌트 전달값.
- `supabase/tests/020_catalog_card_images.sql`: DB의 외부 포스터/업로드 정보 전달, 공동 순위, 홈 메타데이터, 익명/로그인 조회 및 정지 사용자 노출 차단.
- 운영 DB의 임시 테스트 데이터는 트랜잭션에서 모두 rollback한다.
- 수정본은 기존 GitHub → Vercel 배포 경로를 사용한다. 별도 호스팅 주소는 같은 배포가 반영됐다고 가정하지 않는다.
