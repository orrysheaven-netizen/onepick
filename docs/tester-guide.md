# 원픽 첫 테스트 안내

테스트 링크: **[원픽 열기](https://onepick-5cl.pages.dev)**

피드백은 이 링크를 보내 준 운영자에게 전달해 주세요.

원픽은 카테고리마다 내가 가장 좋아하는 아이템 하나와 그 이유를 기록하는 서비스입니다.
아직 테스트 중이라 아이템 수가 적고 화면이나 동작이 바뀔 수 있습니다.
홈에는 사람들이 고른 제품과 최근 원픽 사용자의 한줄평이 표시됩니다. 현재는 원픽이 하나라도 등록된 제품이 홈에 표시될 수 있습니다.
휴대폰의 Chrome 또는 Safari에서 링크를 열어 주세요. 카카오톡 안에서 문제가 생기면
외부 브라우저로 다시 열어 보고, 어느 브라우저에서 문제가 났는지 알려 주세요.

## 10~15분 동안 해볼 일

1. 로그인하지 않고 홈과 탐색에서 다른 사람의 원픽을 열어 보세요.
2. 카카오로 로그인하고 사용할 사용자명을 정해 주세요.
3. 원픽 등록에서 서로 다른 카테고리 3개 이상을 골라 보세요. 초기 테스트는 라면·영화·드라마·포켓몬·음악·유튜브·과자처럼 일상적인 카테고리를 중심으로 진행합니다. 각 한줄평은 다른 사람의 문구를 복사하지 말고 본인의 실제 선택 이유를 짧게 적어 주세요.
4. 프로필에서 방금 등록한 원픽을 확인하고, 이유를 수정하거나 같은 카테고리의
   다른 아이템으로 변경해 보세요.
5. 다른 사람의 원픽에 댓글을 남기고, 원픽 또는 프로필 공유 링크를 다른 브라우저에서
   열어 보세요.
6. 원하는 아이템이 없다면 아이템 등록을 요청해 보세요. 직접 찍은 아이템 사진을 사용하고,
   운영자 승인 후 선택할 수 있다는 안내가 이해되는지 확인해 주세요.
7. 로그아웃한 뒤 다시 로그인해 내 원픽이 유지되는지 확인해 주세요.

작성한 원픽·한줄평·댓글·프로필은 다른 사용자에게 보일 수 있습니다. 테스트에는
실명·연락처 같은 개인정보 대신 공개해도 괜찮은 내용과 아이템 사진을 사용해 주세요.

## 알려주시면 좋은 내용

- 무엇을 하려다가 어디서 막혔는지
- 기대한 결과와 실제 결과
- 이해하기 어려웠던 문구나 버튼
- 가장 유용했던 점과 다시 사용할 의향

오류는 아래 형식으로 보내 주시면 확인하기 쉽습니다.

```text
발생 시각:
휴대폰 / 브라우저:
문제가 난 화면 이름:
직전에 누른 버튼 또는 진행 순서:
예상한 결과:
실제 결과 / 오류 문구:
가능하면 화면 캡처:
```

로그인 직후의 긴 주소에는 인증 정보가 포함될 수 있으니 전체 주소 대신 화면 이름을
적어 주세요. 계정 비밀번호나 인증 코드는 전달하지 않아도 됩니다.
