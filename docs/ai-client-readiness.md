# AI 프로필 연결 상태와 생성 버튼

## 변경 범위

서버 설정이 끝나지 않은 상태에서 사용자가 생성 버튼을 눌러 반복적으로 실패하지 않도록, 기존 프로필 AI 카드에 공개 상태 확인을 연결한다. 이번 변경은 기존 AI 서버나 DB 권한을 바꾸지 않는다.

## 동작

- 본인 프로필에서만 `GET /functions/v1/analyze-profile-taste/status`를 조회한다. 토큰·API 키·사용자 ID·원픽 본문·사진을 보내지 않는다.
- 필수 설정이 없으면 `AI 연결 준비 중`으로 표시하고 생성 버튼을 비활성화한다.
- 네트워크/HTTP/잘못된 JSON/응답 형식 오류는 설정 미완료와 구분해 `연결 상태 확인 필요`로 표시한다.
- 응답 지연은 본문 읽기를 포함해 8초로 제한하고 화면의 조회 취소 신호도 전달한다.
- 30초 간격 전경 갱신과 수동 `연결 상태 다시 확인`을 지원한다. 이 요청은 AI를 호출하거나 생성 할당량을 소비하지 않는다.
- 생성 버튼을 누르면 상태를 다시 확인하고, 확인 실패나 설정 미완료일 때 생성 POST를 보내지 않는다.
- 확인 도중 계정/화면이 바뀌어 카드가 해제되면 이전 카드에서 생성을 시작하지 않는다.
- 상태 확인 실패는 기존 평가 조회 또는 본인의 공개/숨김 버튼을 차단하는 근거로 사용하지 않는다. 기존 RLS와 오래된 평가 재공개 제한은 그대로 유지한다.

## 상태의 의미

`configured: true`는 필수 환경변수가 있다는 뜻이지 OpenAI API 키 유효성, 해당 모델 접근 권한, 결제 설정 또는 실제 평가 문장 품질이 검증됐다는 뜻이 아니다. 상태 확인은 인증/인가를 대신하지 않으며 생성 서버는 계속 실제 사용자를 검증한다.

## 검증

`mobile/scripts/test-profile-ai-status.cjs`의 13개 회귀 검사: 참/거짓 상태, 불필요 필드 제거, 잘못된 응답 거부, 자격 증명 없는 GET, HTTP 오류, 잘못된 JSON, 네트워크 실패, 사전/도중 취소, 요청/본문 시간 제한, 생성 버튼 조건, 잘못된 시간 제한 설정.

로컬에서 같은 TypeScript 구현의 동작 테스트 13개를 실행했다. 통합 타입 검사·회귀 검사·웹 빌드 및 배포 서버 smoke 검사의 최종 결과는 이 변경 커밋의 GitHub Actions에서 확인한다. 이 문서는 실제 유료 모델 호출이나 로그인 브라우저 검증의 성공을 의미하지 않는다.

## 실제 생성의 남은 조건

Supabase `onepick-dev`의 Edge Functions > Secrets에서 `OPENAI_API_KEY` 등 서버 필수 설정을 준비하고 실제 계정으로 모델 생성/미리보기/공개/숨김/원픽 변경을 검증해야 한다. 키 값은 채팅이나 저장소에 적지 않는다. 프런트엔드 배포와 PR 병합은 실제 수행 여부를 별도 보고한다.
