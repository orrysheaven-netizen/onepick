# AI 댓글 공개 상태: 저장 확인과 표시 조회 분리

## 범위

기준 커밋은 `2a1d2440083b9abc58c87360bad6f5f8b5ae4c89`이다. 이번 수정은 PR #47의 클라이언트 코드·검사와 품질 검토 자료다. 원격 DB, 카테고리, AI 서버 코드, API 키, 모델 설정, 운영 배포는 변경하지 않는다.

## 수정한 경로

이전 `setVisibility`는 공개 상태 UPDATE가 성공한 다음 `system_actors`를 다시 조회했다. 작성자 읽기가 실패하면 이미 공개된 데이터와 달리 화면에서 ‘공개 설정을 바꾸지 못했어요’로 처리될 수 있었다.

이제 UPDATE 응답의 댓글 ID, 프로필 ID, 생성·수정 시각, 공개 여부, 오래됨 여부만 검증해 **저장 확인 응답**으로 반환한다. 작성자·댓글 본문 조회는 저장 성공의 조건이 아니다. 본문을 다시 읽는 작업은 별도로 수행하며 그 실패가 저장 확인을 실패로 바꾸지 않는다.

## 보존한 보호

- 요청 전 본인 계정 검증과 요청 중 계정 전환 감지를 유지한다. 바뀐 계정으로 늦게 도착한 결과를 반환하지 않는다.
- 공개 UPDATE는 본인 프로필·화면에서 본 댓글 ID·원본 생성 시각·최신 상태를 함께 비교한다. 마이크로초를 반올림하거나 최신 버전으로 공개를 자동 재시도하지 않는다.
- 숨기기는 이전 댓글 버전을 요구하지 않는다. 원픽 10개나 AI 설정 여부는 공개 상태 쓰기의 조건이 아니다.
- 이미 서버가 처리한 작업을 로그아웃이나 네트워크 실패로 되돌렸다고 주장하지 않는다.
- 새 저장 확인 객체를 완전한 댓글 캐시에 넣지 않는다. 최신 읽기 결과를 오래된 본문으로 덮어쓰지도 않는다.

## 불확실한 결과와 화면 안내

네트워크 거절·중계 서버 오류·잘못된 응답은 저장되지 않았다는 증거가 아니다. 별도 `ProfileAiVisibilityUnconfirmedError`로 분류한다. 원본 오류 본문이나 비밀값을 사용자에게 표시하지 않는다.

> 저장 응답을 확인하지 못했어요. 이미 반영됐을 수 있으니 현재 공개 상태를 확인해주세요.

오류 후 `현재 공개 상태 확인`은 읽기만 수행한다. 공개나 생성 요청을 자동으로 다시 보내지 않는다. 조회가 성공하면 현재 공개/비공개 상태를 설명하고, 실패하면 불확실함을 유지한다. 읽을 수 있는 댓글이 없다는 응답은 ‘저장되지 않았다’나 ‘비공개다’로 단정하지 않는다.

저장 확인을 받았지만 작성자/댓글 표시 조회가 실패하는 경우, 확인된 성공 안내는 오류 화면에서도 남겨 둔다. 화면 해제·계정 전환 후 안내를 갱신하지 않는 기존 범위 보호를 유지한다.

## 검사

- 새 `test-profile-ai-visibility-ack.cjs`: 실제 저장소·응답 검증·훅·카드 모듈에 모의 전송을 연결한 **20개 시나리오**를 로컬에서 통과했다. 저장 후 응답 유실, 저장 전 통신 실패, 버전 충돌, 계정 전환, 작성자 의존 제거, 표시 조회 실패, 읽기 전용 복구를 포함한다. PostgREST처럼 `.then`만 있는 전송도 검사한다.
- 기존 `test-profile-ai-account.cjs`: **62개 시나리오**를 로컬에서 통과했다. 후속 작성자 조회가 제거됐으므로 계정 전환 시점을 실제 UPDATE 응답 단계로 옮겼으며 기존 단언은 제거하지 않았다.
- 새 `test-profile-ai-quality-dataset.cjs`: 8개 가상 사례가 각각 원픽 10개/카테고리 10개, 한줄평 길이 제한, 동일 제품·다른 이유라는 비교 조건을 지키는지 확인했다. 문장의 실제 의미 품질을 통과시킨 검사가 아니다.
- 통합 타입 검사·전체 회귀 검사·웹/DB 검사 결과는 최종 커밋의 CI에서 별도로 확인한다. 로컬 모의 검사는 실제 로그인 브라우저나 원격 DB 네트워크 유실의 검증을 대신하지 않는다.

## 댓글 품질 자료

`qa/profile-ai-quality-cases.cjs`와 `qa/profile-ai-quality-rubric.md`에 원픽 10개짜리 가상 입력 8세트 및 수동 기준을 추가했다. 샘플은 운영 프롬프트나 회원 DB에 넣지 않는다. 실제 모델 출력은 아직 측정하지 않았다. 최소 10개, 나이 제외, 존중하는 위트, 한줄평 우선 원칙은 유지한다.
