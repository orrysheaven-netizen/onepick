# AI 댓글 요청 조건: 현재 공개 원픽 최소 10개

2026-09-19 사용자 결정으로 기존 최소 3개 기준을 **10개**로 변경한다. 이 문서의 조건이 이전 설계 문서와 PR 설명의 3개 기준을 대체한다.

## 동작

- 첫 평가와 재평가 모두 현재 공개된 분석 가능한 원픽 10개 이상에서만 요청한다. 이전 선택 이력은 합산하지 않는다.
- 0~9개: 요청 버튼 비활성화. `공개 원픽 7/10개 · 3개 더 등록하면 요청할 수 있어요.`와 같이 현재/필요 개수를 표시한다.
- 정확히 10개부터 개수 조건을 충족한다. 로그인, 서버 설정 확인, 기존 요청 제한도 계속 적용한다. 10개가 됐다고 자동 생성하지 않는다.
- 생성 후 원픽을 줄여 10개 미만이 되면 재평가도 비활성화한다. 기존 평가의 조회·숨김은 최소 개수 때문에 막지 않는다. 원본 변경 시 자동 숨김/stale 정책은 유지한다.
- 서버는 클라이언트가 보낸 개수를 신뢰하지 않고 공개 RLS로 읽은 원픽을 재계산한다. 10개 미만이면 캐시 반환·생성 슬롯 예약·모델 호출보다 먼저 `AI_NOT_ENOUGH_PICKS`와 `minimum`, `count`, `remaining`을 반환한다.
- 나이 표현 제외, 공격적/부정적 인물평 금지, 한줄평 중심 해석 및 기존 등록 안내 문구는 변경하지 않는다.

## 운영상 의미

개발 DB의 읽기 전용 집계에서 공개·선택 가능·open 카테고리 10개와 공개 제품이 있는 해당 카테고리 10개를 확인했다. 현재 구성에서는 각 카테고리에 하나씩 선택해야 새 기준에 도달한다. 카테고리를 추가하거나 공개 설정을 변경하지는 않았다.

기존 3개 입력의 편집용 문체 샘플은 문체 비교 자료일 뿐, 실제 생성 버튼을 누를 수 있다는 의미가 아니다. 실제 화면/배포 서버 테스트와 샘플 미리보기는 구분한다.

## 검사와 반영 범위

- 기존 계정 회귀 검사의 성공 입력을 10개로 수정하고 3개·9개 거부를 포함한다.
- 신규 `mobile/scripts/test-profile-ai-minimum.cjs`는 실제 서비스, 실제 카드 컴포넌트, 실제 Edge 핸들러 코드를 모의 Auth/DB/HTTP 환경에서 실행한다. 0~9개 거부, 정확히 10개/11개 통과, 진행 문구, 재평가, 기존 숨김 유지, 설정 미완료, 위조된 클라이언트 개수 및 읽을 수 없는 항목을 검사한다.
- 이 검사는 실제 모델 출력의 품질이나 실제 로그인 브라우저의 성공을 의미하지 않는다. 최신 커밋의 CI 결과를 별도로 확인한다.
- 이번 변경은 개발 브랜치의 코드/테스트/문서 변경이다. API 키 설정, 원격 DB 쓰기, 실제 AI 생성, 운영 앱/서버 배포 및 PR 병합은 포함하지 않는다. 기존 공개 버전 확인 결함은 별도 출시 전 수정 항목으로 남는다.
